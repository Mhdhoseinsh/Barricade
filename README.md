# سرور آنلاین Route 9 (جایگزین فایربیس)

فایربیس فقط نقش «رله‌ی پیام» بین بازیکن‌ها رو داشت: ساخت کد اتاق، رزرو جای بازیکن، و رد و بدل کردن حرکت‌ها/دیوارها. کل منطق بازی همیشه توی مرورگر خودِ `index.html` بوده و هیچ تغییری نکرده. این سرور فقط همون نقش رله رو با Node.js + Socket.io انجام می‌ده، روی هاست خودت، بدون فایربیس.

توی `index.html` هم فقط همون تکه‌ی اتصال به فایربیس (حدود ۱۳۰ خط) با یک شیم Socket.io عوض شده که دقیقاً همون توابع قبلی رو داره (`createRoom`, `joinRoom`, `send`, `onMessage`, `onPresence`, `leaveRoom`). هیچ جای دیگه‌ی کد بازی دست نخورده.

## مرحله ۱ — دیپلوی سرور روی Render (رایگان، بدون کارت بانکی)

1. یک ریپازیتوری گیت‌هاب بساز و فقط سه فایل این پوشه (`server.js`, `package.json`, `render.yaml`) رو توش بذار.
2. برو به [render.com](https://render.com) و با گیت‌هاب ثبت‌نام کن.
3. **New → Blueprint** رو بزن و همون ریپو رو انتخاب کن؛ Render فایل `render.yaml` رو می‌بینه و خودش سرویس رو با تنظیمات درست می‌سازه (پلن Free، `npm install` و `npm start`).
   - اگه نخواستی از Blueprint استفاده کنی: **New → Web Service**، ریپو رو وصل کن، Build Command: `npm install`، Start Command: `npm start`، پلن: Free.
4. بعد از دیپلوی، یک آدرس مثل `https://route9-server-xxxx.onrender.com` بهت می‌ده. این آدرس رو نگه دار.

نکته‌ی مهم پلن رایگان Render: اگه ۱۵ دقیقه هیچ ترافیکی نیاد، سرویس می‌خوابه و اولین درخواست بعدش ۳۰-۶۰ ثانیه طول می‌کشه تا بیدار بشه. اگه نمی‌خوای بازیکن‌ها منتظر بمونن، یک سرویس رایگان مثل [cron-job.org](https://cron-job.org) یا UptimeRobot بساز که هر ۱۰-۱۴ دقیقه یک بار آدرس ریشه‌ی سرور (`/`) رو پینگ کنه تا بیدار بمونه.

## مرحله ۲ — وصل کردن `index.html` به سرور

توی فایل `index.html`، دو جا باید آدرس واقعی سرور جایگزین `YOUR-SERVER-NAME.onrender.com` بشه (یک بار توی متای CSP نزدیک بالای فایل، یک بار توی مقدار `GAME_SERVER_URL` نزدیک اسکریپت‌های آخر `</body>`). با جستجو-و-جایگزینی متنی `YOUR-SERVER-NAME.onrender.com` توی کل فایل (بدون `https://`/`wss://`) هر دو جا با هم درست می‌شن.

## مرحله ۳ — آپلود دوباره‌ی `index.html`

فایل ویرایش‌شده رو همون‌جایی که الان سایتت هست (گیت‌هاب پیجز یا هر هاست دیگه) جایگزین نسخه‌ی قبلی کن.

## تست

با دو تب/گوشی مختلف وارد سایت شو، یکی اتاق بسازه و دیگری با کد وصل بشه؛ حرکت و دیوار باید همون‌طور که قبلاً با فایربیس کار می‌کرد، سینک بشه.

## یک نکته‌ی صادقانه درباره‌ی فیلترینگ

فیلترینگ اینترنت ایران این روزها خیلی بی‌ثابته و فقط مخصوص فایربیس نیست. نمی‌شه ۱۰۰٪ تضمین کرد Render (یا هر هاست دیگه‌ای) همیشه از ایران در دسترس بمونه. خبر خوب اینه که چون فقط یک آدرس (`GAME_SERVER_URL`) باید عوض بشه، اگه یک روز Render فیلتر شد، می‌تونی همین سه فایل سرور رو بدون تغییر روی یک هاست رایگان دیگه (مثلاً Northflank یا Glitch) دوباره دیپلوی کنی و فقط آدرس رو توی `index.html` آپدیت کنی.
